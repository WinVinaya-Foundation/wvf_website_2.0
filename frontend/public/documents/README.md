# Report & document PDFs

Drop a PDF here using the exact filename below and its card's "View PDF"
button goes live automatically — no code changes needed. Until a file
exists, that card shows "Coming soon" instead of a link that would 404.

## Naming rule (for anything added later)

Lowercase the title (plus year, if the card has one), replace spaces/punctuation
with a single hyphen, strip anything that isn't a-z or 0-9. This is generated by
`documentFileUrl()` in `src/utils/document.ts` — if that function ever changes,
regenerate this list to match.

Note: the "Coming soon" check is a `HEAD` request done in the browser, so a file
only needs to exist at this exact path under `public/documents/` — nothing else
to configure.
