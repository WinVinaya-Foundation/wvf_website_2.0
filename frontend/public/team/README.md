Our Team page automatically — no code changes needed. Anyone without a matching
file here just shows their initials instead.

Format: `.jpg`, roughly square (it's cropped to a circle), reasonably small
(a few hundred KB — these are avatar-sized, not full-resolution).

## Naming rule (for anyone added later)

Lowercase the full name, replace spaces/punctuation with a single hyphen,
strip anything that isn't a-z or 0-9. This is generated by
`personPhotoUrl()` in `src/utils/person.ts` — if that function ever
changes, regenerate this list to match.
