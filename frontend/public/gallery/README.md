# Gallery photos

Drop a photo in this folder using the exact filename below and it replaces the
themed placeholder panel on the Events & Gallery page automatically — no code
changes needed. Photos are grouped into event albums; each caption below maps
to one photo inside one album.

Format: `.jpg`, roughly 4:3 landscape (it's cropped to fill its frame),
reasonably small (a few hundred KB — these are gallery thumbnails, not
full-resolution).

## Naming rule (for anyone added later)

Lowercase the caption, replace spaces/punctuation with a single hyphen, strip
anything that isn't a-z or 0-9. This is generated by `galleryImageUrl()` in
`src/utils/gallery.ts` — if that function ever changes, regenerate this list
to match. New photos need a matching entry in the right album's `photos`
array in `galleryContent.albums`, in `src/pages/programs/eventsGalleryContent.ts`.
